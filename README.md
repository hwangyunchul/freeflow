# FREEFLOW 품질 관제 대시보드

## GitHub Pages 배포 (3단계)

1. github.com 에서 New repository → 이름 `freeflow-dashboard`, Public 선택, Create.
2. Add file → Upload files → 이 폴더의 `index.html` 과 `.nojekyll` 을 끌어다 놓고 Commit.
3. Settings → Pages → Branch: `main`, Folder: `/ (root)` → Save. 1~2분 뒤 아래 주소가 열립니다.

접속 주소: https://<본인계정>.github.io/freeflow-dashboard/

## 참고
- 화면 수치는 샘플 데이터이며 실제 센서와 연결되지 않았습니다.
- `.nojekyll` 은 없어도 되지만, 있으면 빌드가 빠릅니다.
